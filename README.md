# 🏪 Desafio Consulta Loja

Este repositório contém a solução para o **desafio de consulta a uma loja**, com o objetivo de implementar uma funcionalidade para pesquisar produtos, visualizar detalhes e realizar consultas a partir de um conjunto de dados.

## 📌 Sobre o Projeto

O projeto foi desenvolvido com o intuito de criar um sistema simples de **consulta a produtos em uma loja**. O usuário pode realizar pesquisas por nome, categoria ou outros parâmetros, e visualizar os resultados de forma organizada.

## ⚙️ Funcionalidades

- 🔍 Pesquisa por **nome** e **categoria** de produtos
- 🛍️ Visualização de **detalhes dos produtos**
- 📊 Exibição de resultados organizados e fácil de navegar

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3** (para o layout)
- **JavaScript** (para a interação e lógica de busca)
